# UA FREE Content Tool v1.2.0

Дата релізу: 14.08.2026

## Головне

v1.2.0 переводить UA FREE Content Tool з локального Ollama-етапу на редакційний workflow з Codex / ChatGPT і Rowboat-пам’яттю, розширює медіа та кроспостинг, посилює відновлення після помилок і робить чергу керованою без ручного перескладання пакетів.

## Редакційний workflow

- Один канонічний текст новини для всіх платформ, без прихованого окремого рерайту під кожну мережу.
- Рерайт через Codex / ChatGPT у фоні без видимих консольних вікон Windows.
- Rowboat editorial memory використовує лише стиль і структуру схожих схвалених матеріалів; факти з пам’яті не переносяться в новину.
- Глобальний пошук схожих матеріалів по всіх нових блоках із кількома незалежними кластерами на об’єднання.
- Посилені перевірки мови, фактичної прив’язки та відсутності аналітичних домислів.

## Медіа

- До 10 зображень на одну новину.
- Facebook підтримує multi-photo publication.
- Telegram відправляє галерею послідовно та зберігає точний прогрес.
- Threads і Instagram використовують тимчасово доступні медіапосилання тільки для конкретного файла.
- Telegram-медіа береться тільки з exact post embed, без emoji/background assets і сусідніх постів.
- Instagram підтримує фото, відео/Reels і карусель 2–10 фото.

## Платформи та донат-блок

Фінальна політика v1.2.0:

- Facebook: основний текст у пості, донат-блок у першому коментарі.
- Threads: основний текст у пості/ланцюжку, донат-блок у reply.
- LinkedIn: донат-блок залишається в самому пості.
- Telegram: донат-блок залишається в самому пості або caption.
- Instagram: донат-блок залишається в caption.

Для Facebook донатного коментаря потрібні дозволи `pages_manage_engagement` і `pages_read_user_content` разом із базовими Page permissions.

## Надійність публікації

- Кожна платформа має незалежний target і власний прогрес.
- Відома помилка однієї платформи не повинна блокувати незалежні наступні платформи.
- Facebook і LinkedIn більше не маскують конкретні API-відмови як безликий UNKNOWN там, де результат точно відомий.
- Невизначені мережеві результати блокують сліпий повтор саме ризикового запису, щоб не створювати дублікати.
- Legacy queued payloads нормалізуються під актуальну політику донат-блоку.
- Вимкнення інтеграції очищає її токени/ідентифікатори та прибирає мережу з нових targets до повторного підключення.

## Черга

- Додано кнопку `Перерахувати чергу`.
- Усі pending-пакети можна заново розставити за поточними годинами та інтервалом.
- Уже опубліковані, скасовані, призупинені та in-progress пакети не змінюються.
- Кінець вікна `24:00` підтримується коректно як північ наступної доби.
- Збережено контрольовані паузи між платформами та між простроченими пакетами.

## Інтерфейс і portable

- Прибрано застарілий напис `Рерайт через Ollama`; актуальна кнопка: `Рерайт через Codex / ChatGPT`.
- Portable Data можна переносити між збірками без втрати черги, історії, редакційної пам’яті та налаштувань.
- Windows launcher використовує підписаний Python Software Foundation runtime.
