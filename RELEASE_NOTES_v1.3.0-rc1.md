# UA FREE Content Tool v1.3.0-rc1

Це перший release candidate гілки 1.3, побудований поверх live-accepted v1.2.2 без заміни перевірених механізмів дублювання, медіа та публікації.

## Evidence-first rewrite

- Перед AI-рерайтом формується детермінований `Evidence Pack` із поточних джерел блока.
- Кожне джерело зберігає представлення в пакеті; пізні речення з числами, моделями, назвами, цитатами та атрибуцією можуть витісняти малокорисний довгий вступ.
- Хмарний і локальний AI отримують окремі обмежені бюджети контексту.
- Редакційна пам’ять і Rowboat використовуються тільки як пам’ять стилю та рішень і не є фактичним джерелом.

## Fact Guard

Після генерації детермінований guard перевіряє кандидат без додаткового LLM-виклику:

- числа, роки, відсотки та одиниці вимірювання;
- латинські назви компаній, продуктів і моделей у режимі українського рерайту;
- непідтверджені твердження про першість, найбільший/найшвидший/найпотужніший об’єкт або рекорд;
- додану моделлю невизначеність і припущення, яких немає в поточних джерелах.

Якщо кандидат не проходить Fact Guard, він не зберігається і не потрапляє в чергу.

## Adaptive rewrite

- Перший якісний кандидат використовується без зайвого повторного AI-виклику.
- Якщо перший кандидат заблокований Fact Guard або має слабкий deterministic quality score, запускається один другий прохід через інший AI-провайдер.
- Із валідних кандидатів обирається той, що має кращий deterministic quality score.
- Якщо жоден кандидат не проходить Fact Guard, рерайт блокується, а попередній редакторський текст не перезаписується.

## AI Router

- Збережено перевірений набір production-провайдерів v1.2.2: Codex/ChatGPT, Gemini, NVIDIA, Groq, Cloudflare та локальний резерв.
- Нових AI-провайдерів і нових обов’язкових runtime-залежностей не додано.
- Для задач введено окремі бюджети output/context/timeout; першим профілем 1.3 є `rewrite`.
- Локальний fallback як і раніше повторно використовує вже встановлену Ollama та наявні моделі й нічого автоматично не завантажує.

## Source Health

У вкладці «Джерела» додається постійна діагностика:

- стан джерела;
- скільки нових матеріалів дала остання перевірка;
- коли востаннє був новий матеріал;
- накопичена кількість помилок;
- остання помилка у безпечному скороченому вигляді.

`source_health` створюється як додаткова таблиця через `CREATE TABLE IF NOT EXISTS`. `DATABASE_SCHEMA_VERSION` залишається 8, тому 1.3 RC1 не запускає міграцію існуючої Data лише заради діагностики.

## Що навмисно не переписувалося

- live-accepted global duplicate engine;
- ручне підтвердження merge;
- Media Engine і multi-image workflow;
- platform publishers і duplicate-safe `outcome_unknown` поведінка;
- publication queue, target retry semantics та scheduling;
- AES-GCM формат AI secrets;
- існуюча редакційна пам’ять та історія.

## Acceptance gate для stable 1.3.0

RC1 не стає stable лише через зелені unit tests. Перед promotion потрібні:

1. повний Windows CI на Python 3.11 / 3.12 / 3.13;
2. signed portable build на Python 3.12;
3. GUI startup smoke;
4. Microsoft Defender scan runtime і фінального ZIP;
5. ZIP CRC/path/version validation;
6. запуск у окремій папці з КОПІЄЮ чинної робочої `Data` v1.2.2;
7. live rewrite, включно з Fact Guard / Evidence Pack;
8. контроль, що duplicate grouping, media та черга не мають регресій.
