# UA FREE Content Tool

UA FREE Content Tool is a privacy-first Windows desktop application for collecting, manually grouping, rewriting, scheduling and cross-posting Ukrainian news with a local Ollama model.

Public release **v1.0.0** corresponds to internal validated build **R8 FIX30**.

The application uses one canonical text of up to 900 characters and publishes it to Facebook Pages, Threads, LinkedIn and Telegram. Threads can be split into a main post and replies without silent truncation. Google Drive is used as the media source. Platform credentials and the publication queue remain in the portable `Data` folder.

For complete installation, configuration, security and backup instructions, read [README_UA.md](README_UA.md), [PLATFORM_SETUP_UA.md](PLATFORM_SETUP_UA.md) and [SECURITY_NOTES_UA.md](SECURITY_NOTES_UA.md).
