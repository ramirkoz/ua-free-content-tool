# UA FREE Content Tool v1.0.0

This is the first public release of UA FREE Content Tool, based on internal build R8 FIX30.

## Highlights

- One Ukrainian publication text up to 900 characters.
- Manual grouping of related news reports.
- Topic candidate search without automatic merging.
- Local Ollama rewrite using all sources in a block.
- Editorial memory and remembered exclusions.
- Publishing to Facebook Pages, Threads, LinkedIn and Telegram.
- Google Drive media workflow.
- Queue preservation, partial retry and no duplicate reposting of successful targets.
- Windows portable mode with local encrypted configuration.

## Validation

- 223 tests passed.
- Windows portable build passed.
- Portable startup passed.
- Queue and schema preservation passed.
- Shift multi-selection and Ukrainian grounded-rewrite checks passed.

## Downloads

Use the Windows portable ZIP for normal use. The source ZIP is intended for review and development.

Extract the complete Windows folder. Do not move or run only the EXE. Back up the entire working folder before every update.
