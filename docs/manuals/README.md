# Setup manuals

This directory contains the complete installation and configuration manuals for UA FREE Content Tool v1.0.0 / R8 FIX30.

- `UA_FREE_Content_Tool_Complete_Setup_Manual_EN.pdf` — complete English manual.
- `UA_FREE_Content_Tool_Complete_Setup_Manual_UA.pdf` — complete Ukrainian manual.

The PDFs are generated from `tools/build_setup_manuals.py` by the `Build setup manuals` GitHub Actions workflow. The manuals cover portable installation, checksum verification, first launch, the `Data` folder, Ollama, Facebook Pages, Threads, LinkedIn, Telegram, Google Drive media, source collection, editorial grouping, local rewrite, scheduling, queue recovery, backups, migration, security, and troubleshooting.

The application interface remains Ukrainian, so the English manual shows important Ukrainian UI labels together with their English meaning.
