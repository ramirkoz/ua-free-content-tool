# UA FREE Content Tool v1.4.0-rc1

## Головна зміна

Публікація більше не планується одним спільним пакетом на всі соцмережі. Кожна конкретна сторінка, профіль або канал має власний незалежний потік, власну чергу, власну історію і власний розклад.

## Що змінилося

- Facebook Pages, Instagram accounts, Threads, LinkedIn і Telegram працюють як окремі destinations.
- Кожен destination має власний час початку, завершення та інтервал публікацій.
- Якщо матеріал не вибрано для Telegram, Telegram-слот не витрачається і не зсуває його наступні публікації.
- Черга та історія мають окремі вкладки для кожної сторінки / профілю / каналу.
- У черзі та історії показується наша редакційна назва. Якщо її немає, використовується перший змістовний абзац фінального матеріалу. Вхідні RSS-заголовки більше не є основною назвою публікації.
- Display title фіксується в момент постановки в чергу, тому історія не змінюється заднім числом.

## Instagram

- Додано автоматичне виявлення всіх Instagram Professional accounts, доступних через Facebook Login.
- Кожен знайдений Instagram-акаунт стає окремою ціллю публікації `instagram:<user_id>`.
- Page Access Tokens не копіюються в окремі JSON-файли: Instagram destination зберігає тільки несекретні ID/назви, а токен під час публікації береться з уже зашифрованої конфігурації відповідної Facebook Page.
- Збережена сумісність зі старим одиночним Instagram-підключенням.

## Помилки публікації

- Автоматичні повторні публікації після помилки вимкнено.
- Успіх переходить в історію як `Опубліковано`.
- API error, timeout або невідомий результат переходить в історію як `Завершено з помилкою`.
- Текст помилки зберігається для діагностики, але job більше не повертається в чергу.
- Старі призупинені jobs при переході на v1.4 також переводяться в історію без повторної публікації.

## Медіа

- Один медіафайл більше не видаляється після першої успішної платформи.
- Google Drive media зберігається, поки не завершаться всі destinations, для яких потрібен цей матеріал.
- Після завершення останнього destination, незалежно від успіху чи terminal error, виконується безпечне очищення керованого медіа.

## Міграція

- Старі активні пакети з кількома платформами автоматично розділяються на незалежні одноцільові jobs.
- Відправлені та невдалі цілі не дублюються.
- Існуюча Data, редакційна пам’ять, джерела та історія зберігаються.

## Статус

Це release candidate нової моделі планування. Перед основним релізом потрібен живий Windows-прогін із реальними Facebook, Threads, Instagram, LinkedIn і Telegram destinations.
